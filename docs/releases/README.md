# Release notes

Releases are tagged with the same tag in OpenIMP and open-tx-isp (`vYYYY.MM.DD[-rcN]`, branch `aperto`). The release notes
of the open stack live in this repository; open-tx-isp points here.

| Release | Tag | Date | Release note |
|---|---|---|---|
| RC3 (newest) | `v2026.11.07-rc3` | 2026-11-07 | [RC3.md](RC3.md) |
| RC2 | `v2026.10.25-rc2` | 2026-10-25 | [../RELEASE_NOTES_RC2.md](../RELEASE_NOTES_RC2.md) |
| RC1 | `v2026.10.11-rc1` | 2026-10-11 | [../RELEASE-v2026.10.11-rc1.md](../RELEASE-v2026.10.11-rc1.md) |

The RC1 and RC2 notes keep their original file names so that existing links stay valid; new notes go into this
directory as `RCn.md` / `Release-N.md`. GitHub releases: https://github.com/Lu-Fi/openimp/releases (also on
https://github.com/opensensor/openimp/releases).
